# Research Agenda

**Status:** Active research agenda  
**Rule:** investigate only questions that can materially change the architecture, governance or deployment decision.

---

## R1 — Multi-Agent Value

Questions:

- When do independent agents outperform one strong model?
- How much diversity is needed before “assembly” adds real value?
- How should correlated failure be measured?
- When does cross-evaluation improve calibration versus amplify conformity?
- How should minority high-severity findings be escalated?

**Output required:** testable evaluation protocol, not slogans.

---

## R2 — Human Authority

Questions:

- What makes human approval meaningful rather than ceremonial?
- Which decision classes need cooling-off?
- Which need second-human confirmation?
- When does multi-signature improve governance?
- How should emergency authority expire?
- How can coercion or compromised approval be detected?

---

## R3 — Canonical Family Memory

Questions:

- What belongs in canonical memory?
- How are facts separated from interpretations?
- How are corrections represented?
- How is provenance retained across decades?
- How are access rights inherited or revoked?
- How is sensitive memory partitioned?

---

## R4 — Cryptographic Governance

Questions:

- Which governance actions benefit materially from cryptographic enforcement?
- Which should remain legal / human rather than technical?
- Where are time locks useful?
- How should multi-signature recovery work?
- How can device trust avoid becoming a single point of failure?

---

## R5 — Local + Cloud Boundary

Questions:

- Which workloads must remain local?
- Which can use frontier cloud models?
- What latency / cost / confidentiality trade-offs matter?
- How can providers be swapped?
- What is the minimum sovereign core?

---

## R6 — Family-Office Integration

Questions:

- What systems need connectors?
- Which actions require read-only versus write access?
- How are fiduciary / legal duties represented?
- What approvals are already mandated by existing governance?
- Where would SFII duplicate rather than improve current controls?

---

## R7 — Evaluation

Questions:

- How is decision quality measured?
- What benchmark decisions are safe to simulate?
- How is calibration measured over time?
- How do we test recovery and revocation?
- What evidence is required before calling any component production-ready?

---

## R8 — Long-Horizon Continuity

Questions:

- How does governance survive death, incapacity and succession?
- How are policies interpreted across generations?
- How are obsolete assumptions retired without deleting history?
- How does the system preserve institutional learning without preserving error?
