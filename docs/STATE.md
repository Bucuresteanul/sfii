# Current State

**Project:** SFII — Sovereign Family Intelligence Infrastructure  
**Status:** Concept · Research  
**Maturity:** Architecture under development  
**Evidence cutoff:** 2026-10-08

## Exists Now

- a defined problem: durable family intelligence without surrendering human sovereignty
- the Sovereign Human Authority (SHA) principle
- a proposed separation between intelligence, authority and execution
- a proposed multi-agent assembly model
- a proposed local + cloud infrastructure direction
- a governance architecture with graduated approval controls
- a public threat model
- a public research agenda
- this repository as a public architecture record

## Proposed, Not Implemented

- dedicated sovereign infrastructure
- cryptographic governance
- multi-signature control
- trusted-device authorization
- cooling-off enforcement
- second-human confirmation
- machine-readable decision classes
- multi-agent executive assembly
- local canonical family memory
- cross-model adversarial review
- governed execution connectors

## Not Established

This repository does not currently establish:

- production deployment
- operating customers
- audited security
- formal regulatory compliance
- functioning DAO governance
- functioning 70-agent executive assembly
- deployed dedicated servers
- quantitative decision-performance gains
- complete cost model

## Current Decision

The current question is:

**Can SFII be specified as a testable reference architecture in which AI capability can scale without allowing AI authority to silently expand?**

## Next Bounded Milestone

Define one reference workflow for a consequential family decision and prove that the architecture can keep:

- evidence
- recommendation
- authority
- execution
- verification

separate and auditable.

The milestone is complete when additional architecture detail has low probability of changing the governance or safety design materially.
